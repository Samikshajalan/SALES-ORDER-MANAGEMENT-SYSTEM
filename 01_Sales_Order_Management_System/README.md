# Sales Order Management System

# Project Overview
This project is developed in SAP ABAP based on a business requirement.
The project includes custom table creation and a classical report to display sales order details.

# Technologies Used
- SAP ABAP
- SAP Data Dictionary (DDIC)
- Open SQL
- SAP ECC6.0

# Custom Tables Created
1. Customer Table
   - Stores customer information.

2. Product Table
   - Stores product details.

3. Sales Order Table
   - Stores sales order related iNformation.

# Report Developed
1. Classical Report
- Developed a classical report to fetch and display data from custom tables.
- Implemented basic ABAP reporting concepts.

# Learning Outcome
- Created custom tables using SE11.
- Worked with database tables and internal tables.
- Used Open SQL statements for data retrieval.
- Developed a requirement-based SAP ABAP report.
